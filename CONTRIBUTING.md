# Contributing to leadout

Thanks for taking the time to contribute.

## Set up

```sh
git clone https://github.com/cc-forge/leadout && cd leadout   # nothing to install: Python 3.9+ standard library only
```

## Run the tests

```sh
python3 -m unittest discover -s tests
```

## Branches and pull requests

1. Fork the repository and create a branch from `main`.
2. Make a focused change and add or update tests when behaviour changes.
3. Run the tests above before you open the pull request.
4. Open a pull request and fill in the template.

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:` ...): `fix.py release-notes` groups the release notes by these types.
