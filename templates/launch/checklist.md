# Launch-day checklist

- [ ] Audit score is at least 80 (`/leadout:audit`)
- [ ] The README demo loads on a clean browser session
- [ ] The install command works on a clean machine
- [ ] A release is published with the files users need
- [ ] The social preview image is uploaded in the repository settings
- [ ] Issues and Discussions are enabled and notifications are on
- [ ] Time is blocked to answer comments during the first hours
- [ ] `stats.py collect` was run before the launch and runs again after it
- [ ] Posts go out by hand from one account; never ask anyone to upvote or star <!-- lint-allow -->
