# Code of Conduct

This project follows the Contributor Covenant, version 2.1. The full text is at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and applies to every
space where the project is discussed.

## Reporting

To report unacceptable behaviour privately, open a private report at
https://github.com/cc-forge/leadout/security/advisories/new. Only the maintainers can
read it.
